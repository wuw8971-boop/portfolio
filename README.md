# 钟英杰 · 设计作品集

静态个人作品集网站，包含封面、简历、作品目录。使用 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## GitHub Pages

在仓库 Settings → Pages 中，将 Source 设为 Deploy from a branch，选择 main 分支及 / (root)，保存后等待部署完成。

网站地址由 GitHub Pages 部署结果确认。仓库名为 portfolio 时，预期路径为 https://wuw8971-boop.github.io/portfolio/ 。

## 后续更新

- index.html：页面内容及导航。
- style.css：布局和手机适配。
- app.js：交互。
- assets/：图片。

更新文件并提交到 main 后，GitHub Pages 会自动重新发布。Figma 修改不会自动同步，需要导出素材并更新网页。

画板图目前使用 Figma 预览分辨率，后续可替换为高清导出图片。
